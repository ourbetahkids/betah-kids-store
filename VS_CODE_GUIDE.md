HOW TO OPEN YOUR WEBSITE IN VS CODE (FOR BEGINNERS)

STEP 1: Open VS Code (download it free from code.visualstudio.com if you don't have it)

STEP 2: Click "File" at the top, then "Open Folder"

STEP 3: Find your website folder (it has index.html, styles.css, and images/ inside)

STEP 4: Click the folder name, then click "Open"

STEP 5: You will see all your files on the left side. Click any file to edit it.

STEP 6: Change any text you want. Press Ctrl + S (or Cmd + S on Mac) to save.

STEP 7: To see the website, double-click "index.html" in the folder — it opens in your browser.

THAT'S IT. No complicated coding needed. The work is already done.
